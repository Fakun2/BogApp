# Vistas del GitHub Project

## Backlog
Tabla agrupada por Phase y ordenada por código BOG ascendente. Filtrar Status != Done.

## Priority board
Board agrupado por Priority y Status. Orden recomendado: P0, P1, P2, P3.

## Team items
Tabla agrupada por assignee, con campos Sprint, Size, Area y Target date visibles.

## Roadmap
Timeline usando Start date y Target date, agrupado por Phase.

## My items
Filtro `assignee:@me` con Status, Priority, Sprint y dependencias visibles.
